# URL Quick Reference Guide

## Supported URL Formats

### 1. **Date Only** - Random Location
```
/1600
```
- ✅ Year: 1600
- ✅ Location: Random (any zone)
- ✅ Game mode: Auto-suggested
- ✅ Character: Procedurally generated

---

### 2. **Date + Zone** - Random Location in Zone
```
/1600/europe
/1600/mena
/1600/eastasia
```
- ✅ Year: 1600
- ✅ Location: Random in specified zone
- ✅ Game mode: Auto-suggested
- ✅ Character: Procedurally generated

**Supported Zones:**
- `europe` → Random location in Europe
- `mena` → Random in Middle East & North Africa
- `eastasia` or `asia` → Random in East Asia
- `southasia` or `india` → Random in South Asia
- `africa` → Random in Sub-Saharan Africa
- `northamerica` or `americas` → Random in North America (Pre-Columbian)
- `southamerica` → Random in South America
- `oceania` or `pacific` → Random in Oceania

---

### 3. **Date + Zone + Game Mode**
```
/1600/europe/survival
/1600/mena/exploration
/1600/eastasia/commerce
```
- ✅ Year: 1600
- ✅ Location: Random in zone
- ✅ Game mode: Specified
- ✅ Character: Procedurally generated

**Supported Game Modes:**
- `survival` - Survive harsh conditions
- `exploration` - Discover territories
- `commerce` - Trade and prosper
- `scholarship` - Pursue knowledge
- `leadership` - Build power
- `livelihood` - Support family
- `diplomacy` - Navigate politics
- `legal` - Navigate justice

---

### 4. **Date + Specific Location**
```
/1600/north-china-plain
/1600/thames-estuary
/1600/paris-basin
```
- ✅ Year: 1600
- ✅ Location: Exact map area
- ✅ Zone: Auto-detected
- ✅ Game mode: Auto-suggested
- ✅ Character: Procedurally generated

---

### 5. **Date + Location + Game Mode**
```
/1600/north-china-plain/survival
/1600/thames-estuary/exploration
```
- ✅ Year: 1600
- ✅ Location: Exact map area
- ✅ Game mode: Specified
- ✅ Character: Procedurally generated

---

### 6. **Zone.Region Format**
```
/1600/europe.iberia/survival
/1600/eastasia.japan/exploration
```
- ✅ Year: 1600
- ✅ Zone: europe
- ✅ Region: Iberia (random in region)
- ✅ Game mode: Specified

---

### 7. **Full State (Shareable)**
```
/1600/north-china-plain/survival?state=eyJ2IjoxLC...
```
- ✅ Year: 1600
- ✅ Location: Exact
- ✅ Game mode: Exact
- ✅ Character: Exact same character
- ✅ Map seed: Same world layout

*Generated by share buttons*

---

## How Each Format Works

### **Random Zone Generation**
When you use `/1600/europe`:
1. Parses `europe` → `EUROPEAN` cultural zone
2. Maps to `'Europe'` geographical zone
3. Calls map generator with zone parameter
4. Randomly selects a map area from Europe
5. Generates character appropriate to that location

### **Specific Location**
When you use `/1600/north-china-plain`:
1. Parses `north-china-plain` → "North China Plain"
2. Detects zone: "East Asia"
3. Uses exact map area
4. Generates character for that location

### **Full State Restoration**
When you use `?state=...`:
1. Decodes base64 state parameter
2. Restores exact character
3. Uses exact map seed
4. Recreates identical game

## Tips

### ✅ **DO:**
- Use lowercase for zones: `/1600/europe`
- Use hyphens for map areas: `/1600/north-china-plain`
- Combine date + zone for predictable randomness: `/1600/mena`

### ❌ **DON'T:**
- Mix case: `/1600/Europe` (works but lowercase preferred)
- Use spaces: `/1600/north china plain` (won't work)
- Expect same character: URLs generate new characters unless using `?state=`

## Summary

| URL Pattern | Year | Location | Game Mode | Character |
|-------------|------|----------|-----------|-----------|
| `/1600` | ✅ | Random | Auto | Random |
| `/1600/europe` | ✅ | Random in Europe | Auto | Random |
| `/1600/europe/survival` | ✅ | Random in Europe | Survival | Random |
| `/1600/thames-estuary` | ✅ | Thames Estuary | Auto | Random |
| `/1600/thames-estuary/survival` | ✅ | Thames Estuary | Survival | Random |
| `...?state=xxx` | ✅ | Exact | Exact | **Exact** |

**Key Point:** Only URLs with `?state=` parameter preserve the exact character. All others generate new procedural characters!
