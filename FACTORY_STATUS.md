### Quick Integration (No NPC Toast)
Replace the "Ask for Work" button handler with:
```typescript
onClick={() => {
  const factoryType = getFactoryType(mapData.era, mapData.culturalZone, mapData.region);

  if (!factoryType) {
    showToast({ message: 'No factory work available', type: 'warning' });
    return;
  }

  // Skip NPC negotiation, go straight to contract modal
  setShowContractNegotiation(true);
  setActiveFactoryData({
    factoryType,
    factoryName: structure.name,
    contract: null, // Will be negotiated in ContractNegotiationModal
    npcs: nearbyNpcs
  });

  handleClose(); // Close POI toast
}}
```

Then in App.tsx/ModalHub:
```typescript
{showContractNegotiation && activeFactoryData && (
  <ContractNegotiationModal
    factoryType={activeFactoryData.factoryType}
    factoryName={activeFactoryData.factoryName}
    playerCharacter={playerCharacter}
    overseerNpc={activeFactoryData.npcs[0]} // Use first NPC as overseer
    onAccept={(contract) => {
      setShowContractNegotiation(false);
      setShowFactoryPanel(true);
      setActiveFactoryData(prev => ({ ...prev, contract }));
    }}
    onDecline={() => {
      setShowContractNegotiation(false);
      setActiveFactoryData(null);
    }}
  />
)}
```

This skips the NPCToast binary choice flow but gets the factory panel working faster.
